Your Goal: Start Week 2 with no organizational or technical blockers. You should know where the team works, how work is tracked, and how each active repository runs on your computer.

Expected completion: End of Week 1

Administrative Setup

Complete by end of Week 1

  • Review and sign the Participation Agreement (coordinate with President)
  • Format your resume following AlgoGators' standard template
  • Update LinkedIn with AlgoGators role and add to our organization
  • Submit class schedule (PDF) to your Team Lead and President
  • Review the fund handbook and calendar — familiarize yourself with key dates and policies

Why this matters: These items ensure legal compliance, team coordination, and visibility. They take 1–2 hours total and unblock your ability to participate fully.

Team Platforms & Introductions

Join the organization

  • Accept your Jira invitation, complete your profile, open the team board, and confirm you can view your onboarding work.
  • Join the AlgoGators WhatsApp and Discord, use a recognizable name, and post a short introduction in the appropriate onboarding channel.
  • Confirm OneDrive access to shared research, backtests, and documentation folders
  • Meet personally with John Riley for a Week 1 onboarding conversation covering the team, the development stack, expectations, and where to ask for help.
  • Secure database credentials for PostgreSQL access (coordinate with your Team Lead)
  • Install & configure your development environment:
    • IDE (VS Code, PyCharm, or preferred editor)
    • Python 3.9+ with required libraries
    • C++ compiler (if working on trade engine)
    • PgAdmin or similar for database management
    • Git configured with your GitHub account

Why this matters: These are the systems where the team communicates, assigns work, and solves blockers. Complete the invitations early so you can ask for help while setting up the repositories.

GitHub & Local Repository Setup

Get all six active repositories running locally

  • Join the AlgoGators GitHub organization, enable two-factor authentication, and configure Git with your GitHub account.
  • Clone each repository below into one organized AlgoGators workspace on your computer.
  • Follow each README from a clean checkout, install its dependencies, and run its documented local start, test, or example command.
  • Record the working command and any blocker in Jira. A repository counts as complete when you can run its application, service, tests, or included example locally without an unexplained error.
algogators README →

Monorepo scaffold. Verify its path-filtered CI configuration:

just check-paths
AlgoTerminal README →

Create a virtual environment, install the package, and launch the terminal:

pip install -e . algoterminal
AlgoLens README →

Run both the frontend and API in separate terminals:

cd algolens-frontend && npm install && npm run dev cd algolens-api && pip install -r requirements.txt && python app.py
algosystem README →

Install development dependencies and verify the CLI:

poetry install --with dev poetry run algosystem benchmarks
data-ngin README →

Install the Poetry environment and run the local test suite:

poetry install poetry run pytest tests/
trade-ngin README →

Configure and build the C++ project, then run its tests:

cmake -S . -B build -DCMAKE_BUILD_TYPE=Debug cmake --build build ctest --test-dir build --output-on-failure

Completion check: Show John Riley your local workspace, the command used for each repository, and any remaining Jira blockers before the end of Week 1.
